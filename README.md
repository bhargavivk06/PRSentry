# PRSentry 🛡️
An AI powered GitHub code review bot that automatically reviews Pull Requests.

## Built with
- Python
- FastAPI
- GitHub Webhooks
- Groq AI (Llama 3.3)

## How it works
1. Someone opens a PR on GitHub
2. GitHub fires a webhook to PRSentry
3. Bot reads the code changes
4. Groq AI reviews the code
5. Bot posts review as PR comment!
