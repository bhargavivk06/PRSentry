How to Use PRSentry

1️⃣ Go to your GitHub repo settings

2️⃣ Click Webhooks → Add webhook

3️⃣ Set Payload URL to:

https://prsentry-2m0a.onrender.com/webhook

4️⃣ Set Content type to application/json

5️⃣ Select Pull requests events

6️⃣ Click Add webhook

7️⃣ Open a PR and watch PRSentry review it! 🎉
